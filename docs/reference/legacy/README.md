## 概述

这三份文档写于 2026-10 末到 2026-11-01，当时谱面编辑器还在工程里。之后编辑器、旧曲库页、
旧页面注册表、MessagePack、uPalette、SoftMask、UI Particle 全部移除，所以文中相当一部分内容
**指向不存在的代码**。
