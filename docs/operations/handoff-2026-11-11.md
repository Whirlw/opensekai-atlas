规则要点（已实现）：

- 只有**普通头 / 普通键 / 普通划键**参与「一根手指每帧最多判一条」，重叠按中心距离归一；其它全部独立判定，不占名额。
- 中间点（`LongHoldCombo`）**不在候选集**里，每帧在 `LiveLogic.JudgeDueComboPoints()` 里单独判；判据是「点自己的时间窗内，任意手指落在**点自己的**车道里」，并且「所属条在这次判定的窗口里出现过 Playing/Last」（记忆标志 `_barWasInPlay`）。
- 长条宽限只有一套：`Last` 状态 + `HoldGraceSeconds = 3/60 s ≈ 50 ms`（时间比较，不是帧计数）。
- 头：按下即判（`LongNoteHead.TryJudge` 里直接 `Settle`），未按则在过线后 `JudgeTime` 之外补 Miss。

## 3. 头还没有解耦干净（当前主战场）

`docs/operations/tail-classes.md` §十二 是完整记录，摘要：

- 头的**唯一发布出口**是 `LongNote.cs` 里 `Last → Release` 那一段的 `Head.PublishHeadMiss()`。
- 条「过线时手指不在」（`_headTouched == false`）会**直接** `Scrolling → Release`，不经过 `Last`；随后基类 `NoteBase.cs` 的 `State >= Last` 超时分支把条写成 `Done/Miss`。结果：条结束了，**头一次都没发布**——连击不加，也不掉。
- 真机现象：Test16 开头双押，全 P 只有 6/7。

要做的（§12.4）：把「离开游玩态 ⇒ 先发布头」收敛成**一个出口**，覆盖过线、宽限、`ForceTerminate`、`FinishSilently`、超时、池回收；并回答「条提前结束后头还能不能判」——很可能要把 `LongNoteHead.TryJudge` 开头的 `State == Done` 早退去掉。

## 4. 尾 / flick 还没做的事

`docs/operations/tail-classes.md` §十三：

- flick 尾**只探测标准时间之后的滑动**（标准时间之前的样本不由尾消费）。
- 条与尾之间有 3 帧差，必须保证**同一根尾只发布一次**（不能靠 `State == Done` 早退，要显式 `_published`）。
- 还有 §4 的第 0/2/3 步没做（尾横移后抬手能判、装饰条车道抬手不判邻居、同帧双抬手、类 1 的结算责任）。

## 8. 红线（这些坑踩过，别再踩）

1. **改 C# 不要按行号改**：`LongNote.cs` 有 1500+ 行、Tab 缩进、中文注释。按行号手术连续三次把花括号改坏。用锚点整块替换，改完立刻 `git diff --stat` 看行数。
2. **`NoteList` 同时承担绘制/生命周期与结算**——不要为了结算把它裁掉（试过，61 条红）。
3. **池子会交出脏条**：新增的瞬时字段必须在 `NoteBase.ResetNote()` 复位，`PoolHygieneTests` 用反射盯着这件事。
4. **`MusicScore.ResetNote()` 在谱面绑定之后才跑**，会把绑定期写入的字段清掉；状态要能从时钟/绑定推导，不要缓存。
5. **报告数字必须真跑过**：本轮有一次未执行就写了「已编译 / 已出包 / 时间戳」，被当场抓到。没跑就不要写数字。
6. 测试失败不要留红色代码：改不成就 `git checkout --` 回退，保持 `main` 绿色。
