# 首页、开屏与品牌标

> 目的：说明冷启动的开屏动画、首页（曲库 / 服务器 / 资源包三个入口）和应用图标是怎么做出来的，改哪里、怎么验证。
> 适用读者：改首页、开屏、图标或品牌色的开发者。
> 前置条件：读过 [页面系统](screen-system.md) 里「曲库页不在页面系统里」一节。
> 最后更新：2026-11-18

## 概述

冷启动的链路变成：**开屏 → 首页 → 曲库 → 加载 → 打歌 → 结算 → 回曲库**。

- 开屏和首页都在 `Library.unity` 里，由 `HomeScreen` 负责；曲库页 `LibraryScreen` 照旧构建，只是冷启动时先「不上屏」（没有相机、不放试听）。
- 从打歌回来时直接显示曲库和结算卡；首页在后台待命，按曲库左上角的返回键（或 Android 返回键）回到首页。
- 品牌标、开屏里的标、关于卡里的标和应用图标都由同一份代码 `BrandArt` 画出来，没有手绘贴图。

代码在 `Assets/Game/Runtime/OpenSekai/App/UI/Home/`：

| 文件 | 职责 |
| --- | --- |
| `BrandArt.cs` | 品牌标的几何与配色（纯 C#，无 Unity 类型），按「层」或「图标」栅格化成 RGBA32 |
| `BrandSprites.cs` | 在线程池里把各层画成贴图（首次需要时画一次，整局复用）；`HomeShapes` 生成渐隐条 |
| `BrandEmblem.cs` | 由各层叠成的品牌标，开屏逐层揭示，页头完整显示 |
| `HomeBackdrop.cs` | 背景：曲库同款底色 + 三团缓慢漂移的极光 + 上升的光点（独立子 Canvas） |
| `HomeSplash.cs` | 开屏时间线（含首页入场），一个函数 `Evaluate(t)` 决定每一帧 |
| `HomeView.cs` | 首页布局：页头、三张卡、页脚、提示条；入场 / 展开进曲库 / 收回三段动画 |
| `HomeCards.cs` | 曲库大卡（封面跑马灯、统计、最近游玩）、功能卡（服务器地球仪、资源包卡扇） |
| `HomeAboutPanel.cs` | 「关于」卡：名称、版本、各类素材的来源与许可 |
| `HomeScreen.cs` | 组件本体：相机与 Canvas、首页与曲库之间的切换、返回键、空闲动画时钟 |
| `HomeTheme.cs` / `HomeMotion.cs` | 品牌色、尺寸、时长；动画调度器（截图时可换成手动调度器） |

## 核心内容

### 品牌标

一个「A」：两条腿是透视下的音符轨道（上窄下宽），横杠是判定线，轨道里有一个正在下落的音符，整个字母外面绕一圈倾斜的轨道环（Sekai / Atlas 的「世界」），环上有一颗小卫星。配色是曲库默认强调色延伸出的三色：长春花蓝 `#789CFF` → 紫 `#AC92FF` → 玫瑰粉 `#FF96D2`。

轨道环前半圈从两条腿前面穿过，所以腿在交叉处要「让开」一条缝。开屏时环是后画上去的，于是 `BrandArt` 出两份腿：`RailsWhole`（没缝）和 `Rails`（有缝），环画完的那一帧换成有缝的。

### 开屏时间线

`HomeSplash.Evaluate(t)` 是纯函数，由一条 LitMotion 驱动；点屏幕跳到 `HANDOFF`，截图工具可以停在任意时刻。关键时间点（秒）：

| 时间 | 发生什么 |
| --- | --- |
| 0.10–0.70 | 轨道线从消失点（「A」的顶点）向屏幕底部画出，从中间往两边错开 |
| 0.35–0.80 | 判定线展开 |
| 0.50–1.05 | 一个音符沿中间两轨落下，越近越大 |
| 1.05 | 命中：判定线闪光、两圈冲击波、一簇火花、轨道轻微「顿」一下；背景极光全亮；播放界面音效 `start` |
| 1.12–1.67 | 轨道收拢成「A」：外侧两条细轨收到腿的位置，判定线上升缩短成横杠；内侧轨道收起 |
| 1.48–1.80 | 细轨基本合拢后，实心的两条腿淡入接替它们 |
| 1.60–2.55 | 轨道环扫一圈画上，音符落入「A」中，卫星弹出 |
| 1.90–2.80 | 字标 `OPEN SEKAI ATLAS` 收紧字距淡入，副标题跟上 |
| 3.15–3.90 | 品牌标沿一道弧线飞进页头左上角；字标淡出 |
| 3.30–4.40 | 首页入场：页头、三张卡依次升起，曲库数字从 0 数上来 |

品牌标各层在线程池里画（512 px，超大屏 1024 px，桌面单层约 15 ms）。开屏最多等它 2 秒，期间只显示底色（和系统启动底色一致）。

### 首页

- **曲库卡**（左，占宽度 58.5%）：三列倾斜的封面跑马灯（最近玩过的在前，其次是最新导入的），曲包数和累计游玩次数，最近游玩的曲名与时间，强调色取自最近那首的封面。点它：卡片放大盖住整个屏幕、颜色过渡到曲库底色，然后曲库从同色的幕布里升起。
- **服务器**（右上）：点它，卡片和曲库卡一样放大盖住整页、颜色过渡到底色，然后服务器列表从同色幕布里升起；列表页的返回键反过来，幕布落下后卡片缩回原位。服务器页面本身见 [服务器页面](server-screen.md)。
- **资源包**（右下）：尚未实现，标「即将推出」。点一下会抖动并弹出提示。两张卡上的图画（转动的线框地球仪、扇形的三张资源卡）一直在动。
- **页头**：品牌标、字标、版本号，右侧「关于」按钮。
- **返回键**：首页上按两次（2 秒内）退出；曲库里先关掉打开的菜单 / 卡片，没有可关的才回首页。

### 两个页面怎么共存

各页各有自己的相机（曲库 `depth 100`，首页 `101`，服务器 `102`），同一时刻只开一个。曲库「不上屏」时关相机、关 `GraphicRaycaster`、停试听，但 Canvas 保持启用，好让布局一直按屏幕尺寸算。交接都经过同一种底色：首页的曲库卡最后铺满成底色，曲库的幕布从底色淡出；回去时反过来。

### 应用图标

菜单 `OpenSekai/Brand/Export App Icons`（或 `-executeMethod OpenSekai.EditorTools.BrandIconExporter.ExportFromCommandLine`）会：

1. 写出 `Assets/Graphics/Icons/AppIcon.png`（1024，圆角方块，桌面与默认图标）、`AppIconAdaptiveBackground.png` / `AppIconAdaptiveForeground.png`（432，Android 自适应图标两层，前景落在 66% 安全圆内）和 `docs/images/app-icon.png`（256，README 用）；
2. 设成无压缩、无 mipmap（深色渐变压缩后会出色带）；
3. 在 Player Settings 里指定桌面图标和 Android 自适应图标的两层。

改了 `BrandArt` 的几何或配色，重新跑一次这个菜单即可；PNG 都是生成物，不要手改。

Player Settings 的开屏底色（`m_SplashScreenBackgroundColor`）同时改成了曲库底色 `#0C0F14`，让系统启动画面和开屏第一帧同色。TODO: 待确认 Android 12+ 的系统启动画面在真机上是否使用该颜色。

## 示例

截开屏的几个关键帧和首页（工具会自动切回曲库再拍后面的曲库类截图）：

```powershell
powershell -File Tools/capture-screens.ps1 -HomePage -Intro 0.95,1.12,2.6 -Library
```

`-Intro default` 拍 8 帧，覆盖整段开屏。

## 常见问题与故障排查

- **开屏里品牌标是空的**：各层还没画完（极慢的设备超过 2 秒）。之后会自动补上，不影响流程。
- **首页上点了没反应**：开屏结束前（品牌标飞进页头之前）首页不接收点击；点屏幕会先跳过开屏。
- **截图工具一直等曲库**：确认 `HomeScreen.Current` 存在；`WaitForLibrary` 会调用 `ShowLibraryImmediately()` 把曲库换上屏。
