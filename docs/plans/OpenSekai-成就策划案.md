## 怎样读这张表

- **编号和领取顺序**　编号前缀相同的条目属于同一系列，末尾数字是成就等级。一局可以达成多级，按级依次领取。不同系列独立判定。
- **牌名、阶位和等级**　「奖牌」列给出佩戴时的完整名称。以「全连接力 IV」为例，名称主体是「全连接力」，右侧单独绘制 IV，只显示一次。「虹阶」决定边框；I 至 X、α 至 δ 和 ω 是等级字符。同系列后发的牌提高等级，边框可以沿用。表内「特殊」要求专属边框样式；「终乐章 ω」沿用虹阶边框，另配专属牌面。
- **按行发奖**　达成后可领取，领取后计入已完成数。「否」表示该栏无奖励。头像栏带括号的是已有资源 ID，其余名称是拟制作图案。玩家领取 DAN-01 时没有额外成就奖牌，段位本身的通关铭牌另行发放。

## 演奏记录怎样计数

| 表中用语 | 判定口径 |
| --- | --- |
| 通关、Ranked | 普通模式手动完整结算，生命值大于 0，至少有 1 个计分判定，且已保存有效历史。自动、测试和未保存的演奏跳过。仅标明 Ranked 的目标要求该局谱面快照的 `Ranked` 为真；B30 使用排名系统自己的完整资格判定。段位只进入段位系列、CODA 和累计击打。 |
| 局、张、键 | 每局按记录 ID 去重，每张按谱面内容键 `ScoreKey` 去重；同谱换包或改名仍是一张，同曲异谱可分开计。键数取整谱总连击数，含长按计分点。「以上」「达到」「至少」均含边界。 |
| 累计手动击打 | PERFECT、GREAT、GOOD、BAD 各计 1，MISS 计 0。普通模式失败或退出前已保存的击打也计。段位按挑战 ID 和曲序逐首累加，整套结束时不重复入账。 |
| FC、AP、断连 | 沿用结算奖项。FC 含 AP，要求整谱连击不断且只有 PERFECT 或 GREAT；AP 要求每个计分判定均为 PERFECT。断连数为 GOOD、BAD、MISS 之和。段位逐首判定。 |
| 毫厘之间 | 在符合键数的通关局中，距 AP 一步指全谱仅有 1 个非 PERFECT；距 FC 一步指恰有 1 个断连判定，其余为 PERFECT 或 GREAT。两者同时成立也只加 1 局，AP 加 0。重复通关同谱可累计。 |
| PERFECT 率、评级 | PERFECT 数除以整谱总键数，以原值比较。99.5% 用「PERFECT 数 × 1,000 ≥ 总键数 × 995」判定。评级取结算结果，A 级或以上含 S，S 为最高级。 |
| 时长、密度 | 使用完整曲长 `MusicLengthMs`。一分钟为 60,000 毫秒。平均每秒至少 k 键用「总键数 × 1,000 ≥ 曲长毫秒数 × k」，乘法使用宽整数，曲长须大于 0。LONG 按各行分钟数，DENSE 按各行键数和密度。 |
| 滑键、长按 | 滑键包括带滑动的尾键，每个需要滑动的计分判定只算一次。HOLD 的有效长按链须有首尾且至少有 1 个计分中间点；检查每条链的全部计分中间点。首尾判定只影响整局通关，装饰点跳过。 |
| 重试 | 普通手动游玩中，使用暂停或结算页的「重试」且成功开始同谱新一局，记 1 次。重试次数按同一 ScoreKey 累计，可跨日；从曲库再次选曲不计。单次重开按新局 ID 去重。 |
| 游戏日 | 以结算时当地时间 04:00 为换日点，保存本次所属游戏日；更换时区后沿用已保存的日期。同日同一目标至多增加 1 天，累计天数可间断。 |
| 连续、先后 | 连续 N 局取最近 N 条已保存普通手动记录，按结算时间排序，同刻按记录 ID 排序。失败、退出或条件不符会使包含该局的窗口失效；自动、测试和段位跳过。仅明确要求「不同谱」的窗口排除重谱；ENCORE 按同谱累计通关次数，允许中间穿插其他演奏。同谱前后两次成绩须来自按此顺序排列的独立记录，中间可穿插其他演奏。 |
| 段位 | 一次通过须来自同一挑战记录且最终状态为 Passed。DANPASS 和后光按挑战次数累计，可重打同一套。CODA 的「至少 4 首」按曲序计；若编入重谱，每次出现均须单独达标，第 5 首及以后同样检查。 |
| Best 30 | 每张合资格谱面取个人最佳贡献，取最高 30 张求和，沿用游戏排名结算。表中 6 个目标对应现有分段起点。 |

**新记录所需信息**

- 普通历史已有 `ScoreKey`、Ranked、谱面等级、难度类型、曲长、UTC 结算时刻及各判定数。新记录另存游戏日、重试来源与去重标识。旧局若无法还原结算时的当地日期，仅跳过按日目标；同谱历史相邻不能证明按过「重试」。
- 「箭羽」需整谱滑键计分判定总数及其中 PERFECT 数。「牵丝」需含计分中间点的长按链条数、整谱计分中间点总数及其中 PERFECT 数。分母取完整谱面。旧版 `FlickMissCount` 不能证明所有滑键均为 PERFECT。
- 段位逐曲记录已有 ScoreKey 和结算成绩，CODA 另需能证明当局 Ranked 与 Lv. 的逐曲快照。旧局缺证据时，只跳过依赖该字段的目标；仍可用于击打、段位通过和可核实的后光进度。
- `MedalTiers` 现有五档，`MedalGrades` 已含表中全部字母，`MedalLook` 当前为成就牌传入空等级。实现时须拆分牌名主体与右侧等级，并让预览、领取和佩戴共用同一牌面。「特殊」是新增的成就牌样式；保留段位现有五档边框及存档数值。
