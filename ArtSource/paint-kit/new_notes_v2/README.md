# new_notes_v2

基于当前 `new_notes` 的完整 33 张贴图制作，仅用代码重新配色，原版 `new_notes` 保留不变。

| 原颜色归属 | 新配色 | 适用资源 |
| --- | --- | --- |
| 黄色 | 铂银白 `#F2EFE7` | 所有 critical 音符、箭头、连接点和对应连接线 |
| 绿色 | 熔铜橙 `#FF702E` | 长条、滑键、连接点和对应连接线 |
| 蓝紫色 | 深靛蓝，上部 `#7464FF`、下部 `#435BEB` | 普通蓝色音符 |
| 粉色 | 朱红 `#F04753` | flick 音符、箭头、连接点 |

颜色按音符类别独立转换；不会把旧版某类音符的标志色分配给另一类。原绿色和原黄色不转用于其他类型；新橙色严格限定在红橙色域，与原来的金黄色区分。深靛蓝仍归属原蓝色音符，原粉色改为正红。白色拖尾、星点与高光保持中性，同时线采用冷银色。

全部文件名、画布尺寸、PNG RGBA 格式和逐像素透明度保持不变。现有轮廓、中心细线、拖尾星座、辉光范围、暗光强度及俯视水面效果均沿用。

2026-11-09：两套 `traceLine_eff.png` 均去掉镂空纹理，恢复平滑的四段透明度渐变，配色保留。

`textures` 内只有游戏贴图，预览位于本目录。使用 Windows PowerShell 执行 `tools/build_palette.ps1` 可从当前 `new_notes` 重建此配色。
